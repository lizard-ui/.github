# INSTRUCTIONS — lizard-ui `.github`

## Purpose

This repo must be named **`.github`** on GitHub under the **lizard-ui** organization. It powers the public org profile at [profile/README.md](profile/README.md).

## OKF

* [index.md](index.md) — bundle root
* [specs/features/](specs/features/) — org meta and package map

## Package source

Application and library code live in the public **`lizard-ui`** repository:

* [github.com/lizard-ui/lizard-ui](https://github.com/lizard-ui/lizard-ui) — `src/`, `website/`, `docs/`, `knowledge/`, CI, npm publish

Consumers install **`lizard-ui`** from npm and import `lizard-ui/styles/themes.css`.

## GitHub automation

See [docs/README.md](docs/README.md) for issue templates, Dependabot, and workflows.

When changing org-wide issue forms or CODEOWNERS here, keep the [**lizard-ui**](https://github.com/lizard-ui/lizard-ui) package repo templates aligned if they are copied from this meta-repo.
