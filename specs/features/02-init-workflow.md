| Path / link | Responsibility |
|-------------|----------------|
| **`src/`** | React components, theme context, variant utilities, glass maps |
| **`website/`** | Vite project site — component showcases, docs viewer (`#/docs`) |
| **`docs/`** | Human reference (types, components, styles, examples) |
| **`knowledge/`** | OKF v0.2 bundle for agents; entry via `AGENTS.md` |
| **`dist/`** | Published npm artifacts (ESM, CJS, types, `styles/themes.css`) |
| [npm](https://www.npmjs.com/package/lizard-ui) | **`lizard-ui`** — install with npm, bun, or pnpm |

Default library theme: **`neutral`** (`DEFAULT_THEME`). The project site sets `data-theme="teal"` on `website/index.html`.

Public repo: [github.com/lizard-ui/lizard-ui](https://github.com/lizard-ui/lizard-ui). Org visitors also see [github.com/lizard-ui](https://github.com/lizard-ui) and this **`.github`** meta-repo.
