# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-10-11

### Added

- Live **lizard-ui** organization profile, OKF specs, and governance docs tied to [lizard-ui/lizard-ui](https://github.com/lizard-ui/lizard-ui).

### Changed

- **profile/README.md** — product positioning, npm link, repository table, org assets.
- Issue templates reference **lizard-ui/lizard-ui** vs **lizard-ui/.github**; docs dropdowns list `docs/`, `knowledge/`, `website/`.

### Removed

- **`scripts/`** — init-from-template wizard (no longer used).
- **`templates/`** — adopter placeholder tree.
- **`docs/init-from-template.md`**.

## [0.1.0] - 2026-08-17

### Added

- Public GitHub organization **`.github`** meta-repository: `profile/README.md`, Dependabot, CODEOWNERS, issue templates, PR template, and OKF feature specs.
