# Lizard UI — organization meta (`.github`)

Public [**GitHub organization profile**](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile) and shared governance for [**lizard-ui**](https://github.com/lizard-ui): a **React component library** with Radix primitives, theme tokens, glass variants, and a documented project site.

This repository must be named **`.github`** on GitHub under the **lizard-ui** organization. It does not ship library source; it hosts the org landing page (`profile/README.md`), community docs, and automation shared across org repos.

Run the marketing/docs site locally from the package repo: `bun dev` (`website/` → `localhost:5173`).
